## Codex-anbefaling

Codex kan sette evidensstatus til `EVIDENCE_COMPLETE`, `RECOMMENDED` eller `BLOCKED`, men kan ikke ta eierbeslutningen.

## Eierbeslutning

Bruk én av: `PENDING`, `OWNER_ACCEPTED`, `REJECTED`, `DEFERRED_WITH_SCOPE_REDUCTION`, `SUPERSEDED`. Ved scope-reduksjon skal berørt garanti, release og sikker fallback beskrives.
