# Leveransestige

> **Status:** Operativ scope-visning av §1.3 i `docs/PRODUCT_REQUIREMENTS.md`. Ved konflikt er produktkravet kanonisk.

- **Alpha 0.1:** én kilde, ett mål, bare nye filer, ingen erstatning eller sletting.
- **Alpha 0.2:** erstatning, versjoner, recovery og historikk.
- **Beta:** tre mål, NAS/USB, automatikk og duplikatvisning.
- **1.0:** speiling med karantene og restore.
- **Senere:** reverse, toveis og kontrollert takeover.

Scope-reduksjon kan utsette funksjoner, men kan aldri redusere de absolutte sikkerhetsinvariantene.
