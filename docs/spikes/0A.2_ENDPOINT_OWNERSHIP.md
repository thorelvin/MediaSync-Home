# 0A.2 — Kontrollområde, endpoint-eierskap og SMB-lås

## Mål

Bevise kontrollområdeklassifisering og eksklusivt writer-eierskap mot en dedikert SMB-lab fra to ekte Windows-klienter eller isolerte Windows-VM-er.

All mutasjon krever dedikert labrot med validert `.mediasync_test_root`.

## Eksperimenter

1. `ControlAreaClassifier` for alle ni klassifiseringstilstander.
2. Checksummet `endpoint.json` med kanonisk JSON og eksplisitte algoritmefelt.
3. Global `mutation.lock` fra klient A og avvisning på klient B.
4. Fremmed `owner_installation_id` som read-only.
5. Kontrollert takeover i lab med økt `ownership_epoch`.
6. Avvisning av stale permit/intensjon fra gammel epoke etter reconnect.
7. Nyere kontrollschema som read-only, ikke automatisk nedgradering.
8. Ukjent `.mediasync`-innhold som aldri ekskluderes eller adopteres stille.
9. Cleanup som nekter å krysse installasjonsnamespace eller feil testrot.

## Miljøregel

To prosesser på én maskin er bare lokal harnessvalidering, ikke cross-machine-bevis. Mangler to klienter, bygg reproducerbar harness og manuell kjøreveiledning, marker cross-machine-radene `BLOCKED_BY_ENVIRONMENT`, og stopp ikke uavhengig klassifiseringstest.

## Kvalitetsport

- Bevismatrisen identifiserer begge klienter og SMB-server/share.
- Bare én writer kan holde den globale låsen.
- Gammel epoke kan ikke mutere etter takeover.
- Ingen produksjonsdeling eller ukjent kontrollmappe er endret.
- Codex stopper etter 0A.2.
