# 0A.0 — Miljø- og sikkerhetspreflight

## Mål

Fastslå hva som faktisk kan bevises i tilgjengelig miljø, uten å starte produktimplementasjon eller muterende arkitekturprober.

- `docs/ARCHITECTURE_SPIKE_REPORT.md`

- `artifacts/0a0/**`
- `tools/validate_handoff.py` bare ved en reell valideringsfeil

Ikke endre produktkrav, arkitektur, schemautkast eller andre 0A-instrukser i denne arbeidspakken.

## Oppgaver

1. Registrer Git-baseline og eksisterende arbeidsendringer.
2. Valider pakken og dokumenter kommando/resultat.
3. Inventer operativsystem, verktøy, privilegier, VM-/SMB-lab, filsystemer og kapasitet.
4. Klassifiser hvert hovedbevis:
   - `RUNNABLE_NOW`
   - `RUNNABLE_WITH_LOCAL_FIXTURE`
   - `REQUIRES_USER_LAB_ACTION`
   - `BLOCKED_BY_ENVIRONMENT`
   - `OUT_OF_SCOPE`
5. Bekreft at ingen reelle brukerdata eller produksjonsmål trengs.
6. Beskriv nødvendige labhandlinger uten å utføre dem automatisk.
7. Anbefal neste arbeidspakke basert på tilgjengelig miljø.

## Kvalitetsport

- Ingen produktkode eller muterende labfixture er opprettet.
- Alle fremtidige eksperimenter har eksplisitt miljøstatus.
- Blockers skiller mellom manglende verktøy, manglende privilegium og manglende fler-maskin-lab.
- Rapporten inneholder eksakte kommandoer og versjoner.
- Codex stopper etter 0A.0.
