# 0A.1 — Prosessmodell, named pipe og Job Object

## Mål

Bevise en minimal, ikke-muterende Engine Host-livssyklus, lokal named-pipe-kommunikasjon og sikker child-containment på Windows.

Ingen produksjonsmoduler under `src/` og ingen muterende commands.

## Eksperimenter

1. Minimal Engine Host discovery/readiness over local-only named pipe.
2. Interaktiv klient og Task Scheduler-lignende ikke-interaktiv sesjon under samme bruker.
3. Reconnect, host-restart og protokollmismatch.
4. Verifisering av faktisk klienttoken/SID/session, ikke et selvrapportert rollefelt.
5. Instrumentert child opprettet `CREATE_SUSPENDED`.
6. Job Object assignment med kill-on-close og blokkert breakaway før resume.
7. Negativ test som feiler dersom child observerer én instruksjon før containment.
8. Host-krasj/close som avslutter child deterministisk.

## Kvalitetsport

- Ingen child kjører før containment er bekreftet.
- Remote eller feil bruker-/sesjonskontekst avvises etter dokumentert policy.
- Reconnect skaper ikke en ny logisk kommandoeffekt.
- Task Scheduler-eksperiment som mangler miljø markeres separat blokkert; Job Object-eksperimentet kan fortsatt fullføres.
- ADR-ens `evidence_status` kan bli `EVIDENCE_COMPLETE` eller `RECOMMENDED`; `owner_decision` forblir eierstyrt.
- Codex stopper etter 0A.1.
