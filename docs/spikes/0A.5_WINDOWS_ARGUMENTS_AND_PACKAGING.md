# 0A.5 — Windows-sti, argumenter og pakking

## Mål

Bevise sikker systemprogram-resolusjon, korrekt Windows-argumentserialisering og en minimal reproducerbar build på ren Windows-VM.

## Eksperimenter

1. `GetSystemDirectoryW`-probe og kontrollert resolusjon av `Robocopy.exe`.
2. Én kanonisk Windows argv-builder.
3. Round-trip for Unicode, mellomrom, UNC, trailing backslash, tomme argumenter og grensenær kommandolinje.
4. Negativ validering av forbudte Robocopy-flagg etter endelig serialisering.
5. Minimal Python/PySide6/BLAKE3/Win32-app.
6. Reproduserbar pakking med valgt strategi.
7. Oppstart på ren Windows-VM uten utviklingsmiljø.
8. Registrering av binary hashes, verktøyversjoner og manglende runtimeavhengigheter.

## Kvalitetsport

- Systemsti avledes fra Windows API, ikke blind miljøvariabel.
- Argumenter round-tripper uten shell.
- Den rene VM-en kan starte artefakten, eller testen er eksplisitt blokkert med reproduserbar kjøreveiledning.
- Codex stopper etter 0A.5.
